# Privacy-Policy-Chatbot-ESEIAAT

Aquest chatbot pot registrar preguntes que no es poden resoldre automàticament amb l’objectiu de millorar el servei.

Les dades que es poden registrar inclouen:
-La pregunta introduïda per l’usuari
-L’idioma de la consulta
-Informació contextual relacionada amb la consulta

Aquestes dades s’emmagatzemen en un Google Sheet gestionat per l’equip de l’ESEIAAT i s’utilitzen exclusivament per:
-Millorar les respostes del chatbot
-Detectar mancances en la informació disponible

No es fa cap ús comercial de les dades ni es comparteixen amb tercers.
Per qualsevol dubte, es pot contactar amb l’ESEIAAT.
